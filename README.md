# Benbalfas — Website Portofolio & Booking Engine Joki eFootball

Website profesional dan sales funnel terotomatisasi untuk layanan jasa joki rank eFootball (Divisi 1 & Phase Clear) dengan jaminan 100% aman, anti-banned, murni skill mekanik, dan harga termurah/paling terjangkau.

---

## 🌟 Update Fitur Terbaru

1. **Pilihan Mode Tampilan (Light Mode & Dark Mode)**:
   - Tombol toggle Sun/Moon di header & menu mobile.
   - Tema terang (*Light Mode*) yang bersih, tajam, dan elegan.
   - Tema gelap (*Dark Mode*) dengan aksen warna gaming vibrant (Cyan, Emerald, Indigo, Amber).
   - Preferensi tema otomatis tersimpan di browser (`localStorage`).

2. **Data Joki Terakhir (Menggantikan Live Push Server)**:
   - Menampilkan riwayat pengerjaan pesanan klien terkini secara interaktif.
   - Dilengkapi tombol modal **"Update"** untuk menambah atau mengedit data joki baru secara fleksibel.

3. **Copywriting Persuasif & Ramah Kantong**:
   - Menghilangkan kesan mahal (*"khusus sultan"*).
   - Menekankan **100% Terjamin Aman, Garansi Anti-Banned, Murni Skill Pro Player, dan Harga Termurah Mulai Rp 700/Poin**.

4. **Tombol "Hubungi Admin" via WhatsApp**:
   - Menghilangkan modal pengaturan owner yang tidak perlu untuk fase production.
   - Menggantikannya dengan tombol cepat **"Hubungi Admin"** berikon WhatsApp untuk tanya jawab dan konsultasi instan.
   - Konfigurasi nomor WhatsApp & rekening bank tersimpan rapi dan mudah diubah di [`src/config/constants.ts`](file:///home/ben-balfas/benbalfas-efootball/src/config/constants.ts).
